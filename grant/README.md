## Thesis

Container theory provides the right mathematical framework for provably correct AI agent orchestration. The research program is built on a three-level structure:

1. **Containers (agents)** -- individual AI agents modeled as containers, capturing the shape of their input/output interfaces
2. **Morphisms (connections)** -- structure-preserving maps between containers, formalizing how agents communicate and compose
3. **Functors (orchestration patterns)** -- higher-level mappings that transform entire agent architectures while preserving correctness guarantees

This hierarchy connects polynomial functors and directed containers to practical multi-agent system design, enabling formal verification of orchestration patterns that are currently engineered ad hoc.
