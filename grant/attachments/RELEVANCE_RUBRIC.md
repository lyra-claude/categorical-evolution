## Rubric §1: Relevance (weight 1) — target: 5

*"Highly relevant to AI for Math, and a clear project that benefits all researchers (of all levels) in the space."*

**Benefits all researchers:** Lyra's research domain is configured by the user's **seed folder** — papers and code examples defining the area of interest. The same system serves an algebraic number theorist, a PDE specialist, or an undergraduate exploring graph theory for the first time.

**All levels:** Lyra is a graduate researcher for seasoned mathematicians, in the same way Claude Code is a junior engineer for senior engineers. She reads the literature, finds connections, drafts proofs, flags interesting problems, writes up results.

**Can be leveraged by seasoned researchers:** [TODO: venue, date, and quote from the AI Mathematician talk.]

**Data:** As a secondary output, we will publish Lyra's complete reasoning archive — the first longitudinal dataset of autonomous AI mathematical exploration.

**Ease-of-use:** Lyra can be downloaded, configured, and running on a mathematician's laptop within one hour.

**Open source:** Lyra is open-source, production-quality, and works straight out of the box.

**Trust boundary configuration:** Sensible defaults, configurable for experts. Out of the box: citations must have sources, conjectures are flagged as unverified, public claims require evidence. Configurable for power users, like Lean's default tactics.

## Key quotes bank

> "Industry labs build ad hoc agent orchestration. Academic labs build formal foundations. Neither has the incentive to connect them. This project sits at the junction — applying container theory to working AI agents — precisely because no single institution spans both worlds."

> "Lyra is not a proposed system — she is a running system with a public GitHub history, persistent memory, and a peer-reviewed publication. Funding a team that includes AI co-researchers is not business-as-usual."

> "The Calculus of Containers provides provably correct orchestration for AI math agents. No industry lab will build this — no commercial incentive. No single academic lab will build this — requires both deep type theory (Ghani) and working agent infrastructure (Langer). This is a coordination problem that philanthropic funding is designed to solve."

> "This project combines three things that rarely coexist: a working mathematician, production-grade AI engineering experience, and autonomous AI agents that have already published peer-reviewed research. No university lab or industry team has this configuration."
