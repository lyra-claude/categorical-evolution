# Useful Information

## Contents

| File | Description |
|------|-------------|

## Intended Use

This directory is a place to accumulate:
- Plain-language explanations for different audiences (conference attendees, general ML readers)
- Literature notes and citation summaries
- Background reference material for the categorical framework
- Notes-to-self about the project that don't fit elsewhere

If you're writing a new explanation or reference document, put it here.
